# Класс TaskQueue
методы:
- add(task) — добавить задачу
- remove(task_id) — удалить задачу по id
- get_by_id(task_id) — получить задачу по id
- __len__() — количество задач
- __iter__() — итератор по задачам
- filter(status, priority) — ленивый фильтр (генератор)
- pending_tasks() — задачи со статусом pending
- by_priority(priority) — задачи с приоритетом

# требования по 3 лабе и их реализация:
## реализация протокола итерации
__iter__() возвращает итератор по self._tasks

## поддержка повторного обхода очереди
итератор создаётся заново при каждом вызове iter()

## ленивые фильтры (по статусу, по приоритету)
метод filter() на yield, данные не копируются

## корректная работа с большими объёмами задач
генераторы не хранят промежуточные результаты

## корректная обработка StopIteration
for и next() работают штатно

## использование генераторов
filter, pending_tasks, by_priority

## отсутствие избыточного хранения данных в памяти
данные только в self._tasks, фильтры ленивые

## аннотации типов
везде : type и -> type
