# second_sem
## лабораторная работа 1
## структура
 ├── src/        
 │   ├── file_source.py       # источник из файлов  
 │   ├── generator_source.py  # источник генератор     
 │   ├── logger.py            # логггировние
 │   ├── task_source.py       # контракт
 │   ├── task.py              # модель задач
 │   ├── main.py              #запуск   
 ├── test/  
 │   ├── test_file_source.py
 │   ├── tets_generator_source.py
 │   ├── test_protocol.py
 │   ├── tets_task.py
 ├── polisha.log              # файл с записью логов

# что и как происходит

# работа с файлами 
- читает json файлы
- создает задачи из каждой записи
- проверяет что файл существует
- проверяет что формат правильный

# генерация
- создает задачи по запросу
- проверяет что count > 0
- логирует каждое действие

# контракт protocol
- все источники имеют метод get_tasks()
- проверка через isinstance()
- можно легко добавить новый источник

# логгировние
- все действия пишутся в polisha.log
- ошибки тоже логируются
- видно, что происходит каждый шаг программы

# работа 
- запускаем программу 
- чтение файла(создание 3х задач из файла)
- для источников: проверяем, что источник. 
- пишем имя источника. 
- получаем задачи.
- считаем кол-во.  
- выводим резульатт

# Protocol, runtime_checkable
- в файле task_source.py создан контракт, которому долдны соответвовать источники. 
т.е. любой класс у которого есть name и get_tasks() считается источником
- @runtime_checkable позволяет проверять соответствие через isinstance()
